# ISP调试工具服务

## 概述

&emsp;&emsp;ISP调试工具服务its模块，是配合ISP调试工具的设备服务端模块，通过网络连接，收发处理工具端的操作。

<br/>

## API参考

&emsp;&emsp;本模块提供API参考，如下表所示。

| **函数接口**          | **描述**         |
| --------------------- | ---------------- |
| AK_EXT_ITS_GetVersion | 获取模块的版本号 |
| AK_EXT_ITS_Start      | 启动its服务      |
| AK_EXT_ITS_Stop       | 停止its服务      |
<br/>

## 版本信息获取

### **AK_EXT_ITS_GetVersion**

&emsp;&emsp;【描述】

&emsp;&emsp;获取模块的版本号。

&emsp;&emsp;【语法】

```c
    const AK_CHAR* AK_EXT_ITS_GetVersion(AK_VOID);
```

&emsp;&emsp;【返回值】

| **返回值** | **描述** |
| ---------- | -------- |
| 模块版本号 | 成功     |
| NULL       | 失败     |

&emsp;&emsp;【需求】

&emsp;&emsp;库文件：libapp_its.a或者libapp_its.so

&emsp;&emsp;头文件：ak_its.h

&emsp;&emsp;【接口调用顺序】

&emsp;&emsp;任何位置都可以调用。

<br/>

## 启动/停止服务

### **AK_EXT_ITS_Start**

&emsp;&emsp;【描述】

&emsp;&emsp;启动its服务。

&emsp;&emsp;【语法】

```c
    AK_VOID AK_EXT_ITS_Start(AK_U32 u32Port);
```

&emsp;&emsp;【参数】

| **参数名称** | **描述** | **取值范围**                                                 | **输入/输出** |
| ------------ | -------- | ------------------------------------------------------------ | ------------- |
| u32Port      | 端口     | 可以自定义用多少端口，工具端连接设备时要与此接口设置的端口对应。工具端默认端口8765，可在工具端连接时修改。 | 输入          |

> **安全提示：** ITS 服务仅用于调试。请只在隔离的开发网络中启动，并用主机和网络防火墙限制可连接设备；调试结束后调用 `AK_EXT_ITS_Stop`。修改端口号不能代替访问控制。

&emsp;&emsp;【返回值】

| **返回值** | **描述** |
| ---------- | -------- |
| AK_VOID    | -        |

&emsp;&emsp;【需求】

&emsp;&emsp;库文件：libapp_its.a或者libapp_its.so

&emsp;&emsp;头文件：ak_its.h

&emsp;&emsp;【接口调用顺序】

```c
    AK_EXT_ITS_Start(8765);
    ...
    AK_EXT_ITS_Stop();
```

&emsp;&emsp;【接口配对关系】

&emsp;&emsp;AK_EXT_ITS_Stop;

<br/>

| AK_VOID      | -        | -            | -             |

&emsp;&emsp;【返回值】

| **返回值** | **描述** |
| ---------- | -------- |
| AK_VOID    | -        |

&emsp;&emsp;【需求】

&emsp;&emsp;库文件：libapp_its.a或者libapp_its.so

&emsp;&emsp;头文件：ak_its.h

&emsp;&emsp;【接口调用顺序】

```c
    AK_EXT_ITS_Start(8765);
    ...
    AK_EXT_ITS_Stop();
```

&emsp;&emsp;【接口配对关系】

&emsp;&emsp;AK_EXT_ITS_Start;
