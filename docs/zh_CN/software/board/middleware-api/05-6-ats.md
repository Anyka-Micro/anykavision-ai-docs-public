# 音频工具服务

## 概述

&emsp;&emsp;ATS模块主要负责启动设备端的server，等待音频调试工具PC端的client进行连接，当与音频调试工具PC端连接成功之后，与音频调试工具PC端进行数据的交互。

<br/>

## API参考

&emsp;&emsp;本模块提供API参考，如下表所示。

<br/>

## 函数接口列表

| **函数接口**          | **描述**    |
| --------------------- | ----------- |
| AK_EXT_ATS_GetVersion | 获取版本号  |
| AK_EXT_ATS_Start      | 启动ats服务 |
| AK_EXT_ATS_Stop       | 关闭ats服务 |

<br/>

## 获取版本号

&emsp;&emsp;AK_EXT_ATS_GetVersion

&emsp;&emsp;【描述】

&emsp;&emsp;获取版本号。

&emsp;&emsp;【语法】

```c
const AK_CHAR* AK_EXT_ATS_GetVersion(AK_VOID);
```

&emsp;&emsp;【返回值】

| **返回值** | **描述** |
| ---------- | -------- |
| 模块版本号 | 成功     |
| NULL       | 失败     |

&emsp;&emsp;【需求】

&emsp;&emsp;库文件：libplat_ai.a、libplat_ao.a、libplat_ats.a、libplat_vqe.a、libakaudiofilter.a或者libplat_ai.so、libplat_ao.so、libplat_ats.so、libplat_vqe.so、libakaudiofilter.so

&emsp;&emsp;头文件：ak_ats.h

&emsp;&emsp;【接口调用顺序】

&emsp;&emsp;任何位置都可以调用。

&emsp;&emsp;【接口重入性】

&emsp;&emsp;函数可重入。

## 启动ATS服务

AK_EXT_ATS_Start

&emsp;&emsp;【描述】

&emsp;&emsp;启动ATS服务。

&emsp;&emsp;【语法】

```c
    AK_S32 AK_EXT_ATS_Start(AK_U32 u32Port);
```

&emsp;&emsp;【返回值】

| **返回值** | **描述**       |
| ---------- | -------------- |
| AK_SUCCESS | 成功           |
| 其他       | 请参考错误码。 |

&emsp;&emsp;【需求】

&emsp;&emsp;库文件：libplat_ai.a、libplat_ao.a、libplat_ats.a、libplat_vqe.a、libakaudiofilter.a或者libplat_ai.so、libplat_ao.so、libplat_ats.so、libplat_vqe.so、libakaudiofilter.so

&emsp;&emsp;头文件：ak_ats.h

&emsp;&emsp;【接口调用顺序】

&emsp;&emsp;在AK_BASE_SdkInit之后，AK_BASE_SdkExit之前调用

&emsp;&emsp;【接口重入性】

&emsp;&emsp;函数可重入。

## 停止ATS服务

AK_EXT_ATS_Stop

&emsp;&emsp;【描述】

&emsp;&emsp;停止ATS服务。

&emsp;&emsp;【语法】

```c

```

&emsp;&emsp;【返回值】

| **返回值** | **描述**       |
| ---------- | -------------- |
| AK_SUCCESS | 成功           |
| 其他       | 请参考错误码。 |

&emsp;&emsp;【需求】

&emsp;&emsp;库文件：libplat_ai.a、libplat_ao.a、libplat_ats.a、libplat_vqe.a、libakaudiofilter.a或者libplat_ai.so、libplat_ao.so、libplat_ats.so、libplat_vqe.so、libakaudiofilter.so

&emsp;&emsp;头文件：ak_ats.h

&emsp;&emsp;【接口调用顺序】

&emsp;&emsp;在AK_EXT_ATS_Start之后，AK_BASE_SdkExit之前调用

&emsp;&emsp;【接口重入性】

&emsp;&emsp;函数可重入。
