# 音频输出

## 概述

&emsp;&emsp;音频输出模块（AO模块）主要负责接收ADEC模块解码后的码流，然后按用户配置的输出协议输送到外围视频设备播放。

&emsp;&emsp;AO模块对于不同平台，支持的设备不同。

| **芯片简称** | **DAC** | **I2S0** |
| ------------ | ------- | -------- |
| KM02G系列芯片  | 支持    | 暂不支持 |

<br/>

```C
    typedef struct akAUDIO_OUT_PARAM_S

        AUDIO_SAMPLE_RATE_E enSampleRate;       //sample rate
        AUDIO_SAMPLE_BIT_E  enSampleBits;       //samplt bits now only support 16bit
```

## 打开/关闭模块

### **AK_MPI_AO_SetPubAttr**

&emsp;&emsp;【描述】

&emsp;&emsp;设置AO设备属性。

&emsp;&emsp;【语法】

```c
    AK_S32 AK_MPI_AO_SetPubAttr(AK_S32 s32AoDevId, AUDIO_OUT_PARAM_S *pstParam);
```

&emsp;&emsp;【参数】

| **参数名称** | **描述**                 | **取值范围**          | **输入/输出** |
| ------------ | ------------------------ | --------------------- | ------------- |
| s32AoDevId   | 音频输出模块设备号       | 参考AUDIO_AO_DEV_ID_E | 输入          |
| pstParam     | 音频输出模块输入参数指针 | 参考AUDIO_OUT_PARAM_S | 输入          |

&emsp;&emsp;【返回值】

| **返回值** | **描述**       |
| ---------- | -------------- |
| 0          | 成功。         |
| 其他       | 请参考错误码。 |

&emsp;&emsp;【错误码】

| **错误码**                | **描述**           |
| ------------------------- | ------------------ |
| ERROR_AO_DEV_ALREADY_OPEN | AO设备已经打开     |
| ERROR_TYPE_POINTER_NULL   | 参数指针为空       |
| ERROR_TYPE_INVALID_ARG    | 参数不正确         |
| ERROR_AO_DEV_ID_NULL      | AO内部设备句柄为空 |

&emsp;&emsp;【需求】

&emsp;&emsp;库文件：libplat_ao.so、libakaudiofilter.so、libplat_vqe.so或者libplat_ao.a、 libakaudiofilter.a、libplat_vqe.a

&emsp;&emsp;头文件：ak_ao.h

&emsp;&emsp;【接口调用顺序】

```c
    /* Step 1: 配置设备公共属性 */
    AK_S32 s32AoDevId = DEV_DAC0;
    AUDIO_OUT_PARAM_S pstParam = {0};
    pstParam.enSampleRate = AK_AUDIO_SAMPLE_RATE_8000;
    pstParam.enSampleBits = AK_AUDIO_SMPLE_BIT_16;
    pstParam.enSoundMode = AUDIO_SOUND_MODE_MONO;
    stAoParam.u32ChnCnt = 1;
    stAoParam.u32SrcCnt = 1;
    // 配置DAC属性
    pstParam.stDacConfig.sReserved = 0;

    AK_S32 ret = AK_MPI_AO_SetPubAttr(s32AoDevId, &pstParam);
    if (ret) {
        return ERROR;
    }

    AUDIO_OUT_PARAM_S attr;
    memset(&attr, 0x0, sizeof(attr));
    ret = AK_MPI_AO_GetPubAttr(s32AoDevId, &attr);
    if (ret) {
        return ERROR;
    }

     /* Step 2: 使能AO设备 */
    ret = AK_MPI_AO_Enable(s32AoDevId);
    if (ret) {
        return ERROR;
    }

    /* Step 3: 设置通道属性 */
    ret = AK_MPI_AO_LoadConf(s32AoDevId, s32AoChnId, spchConfFile, spchConfSection);
    if (ret) {
        return ERROR;
    }

    /* Step 4: 使能通道 */
    ret = AK_MPI_AO_EnableChn(s32AoDevId, s32AoChnId);
    if (ret) {
        return ERROR;
    }

    FRAME_S stFrame = {0};
    /* Step 5: 播放音频数据 */
    while(1) {
      // Do something*
      ret = AK_MPI_AO_SendFrame(s32AoDevId, s32AoChnId, pu8SendPcmData,s32SendPcmLen, 	               ps32PlayPcmLen, s32TimeOut);
      if (ret) {
         return ERROR;
      }

      if (PlayEnd) {
         ret = AK_MPI_AO_GetBufStatus(s32AoDevId, s32AoChnId, &stBufStatus);
	     if (ret) {
                return ERROR;
         }
         AoRemainLen = stBufStatus.s32VqeBufRemainLen + stBufStatus.s32DevBufRemainLen;
         /*get flush time to play remain data*/
         FlushTime =  AudioLenToInterval(s32SampleRate, AK_AUDIO_SMPLE_BIT_16,
                                         s32SoundMode, AoRemainLen);
         ret = AK_MPI_AO_Flush(s32AoDevId, s32AoChnId);
	     if (ret) {
                return ERROR;
         }
      }
    }
    /* Step 6: 关闭通道 */
    ret = AK_MPI_AO_DisableChn(s32AoDevId, s32AoChnId);
    if (ret) {
        return ERROR;
    }
    /* Step 7: 关闭设备 */
    ret = AK_MPI_AO_Disable(s32AoDevId);
    if (ret) {
        return ERROR;
    }
```

&emsp;&emsp;【接口配对关系】

```c
AK_S32 AK_MPI_AO_GetPubAttr(AK_S32 s32AoDevId, AUDIO_OUT_PARAM_S *pstParam);
```

&emsp;&emsp;【接口重入性】

&emsp;&emsp;调用AK_MPI_AO_Open后，如果不调用AK_MPI_AO_Close，重复打开会提示错误。

> **注意：**AO模块只能打开同一个设备一次，重复打开同一个设备会返回错误。

<br/>

&emsp;&emsp;【语法】

```C
     AK_S32 AK_MPI_AO_SetGain(AK_S32 s32AoDevId, AK_S32 s32AoChnId, AK_S32 s32Gain);
```

| s32AoChnId    | 音频输出模块通道号 | 最小值为0，最大值参考AUDIO_OUT_PARAM_S中u32ChnCnt取值，最大值=u32ChnCnt-1。 | 输入          |
| s32Gain | 设置的模拟增益单位是dB | DAC gain范围：[-24, 0dB]，其中 -9dB、-11dB、-13dB、-15dB、-16dB、-17dB、<br/>-19dB、-20dB、-21dB、-22dB、-23dB无法配置，0dB为声音不放大。 | 输入 |

| **返回值** | **描述**     |
| ---------- | ------------ |
| 0          | 成功         |
| 其他       | 请参考错误码 |

&emsp;&emsp;【错误码】

| **错误码**               | **描述**       |
| ------------------------ | -------------- |
| ERROR_AO_DEV_HANDLE_NULL | AO设备句柄为空 |
| ERROR_TYPE_INVALID_ARG   | 参数不正确     |
| ERROR_AO_DRIVER_FAILED   | 驱动设置失败   |

&emsp;&emsp;【需求】

&emsp;&emsp;库文件：libplat_ao.so、libakaudiofilter.so、libplat_vqe.so或者libplat_ao.a、libakaudiofilter.a、libplat_vqe.a

&emsp;&emsp;头文件：ak_ao.h

&emsp;&emsp;【接口调用顺序】

```C
 /* Step 1: 配置设备公共属性 */
    AK_S32 s32AoDevId = DEV_DAC0;
    AUDIO_OUT_PARAM_S pstParam = {0};
    pstParam.enSampleRate = AK_AUDIO_SAMPLE_RATE_8000;
    pstParam.enSampleBits = AK_AUDIO_SMPLE_BIT_16;
    pstParam.enSoundMode = AUDIO_SOUND_MODE_MONO;
    stAoParam.u32ChnCnt = 1;
    stAoParam.u32SrcCnt = 1;
    // 配置DAC属性
    pstParam.stDacConfig.sReserved = 0;

    AK_S32 ret = AK_MPI_AO_SetPubAttr(s32AoDevId, &pstParam);
    if (ret) {
        return ERROR;
    }

    AUDIO_OUT_PARAM_S attr;
    memset(&attr, 0x0, sizeof(attr));
    ret = AK_MPI_AO_GetPubAttr(s32AoDevId, &attr);
    if (ret) {
        return ERROR;
    }

     /* Step 2: 使能AO设备 */
    ret = AK_MPI_AO_Enable(s32AoDevId);
    if (ret) {
        return ERROR;
    }

    /* Step 3: 设置通道属性 */
    ret = AK_MPI_AO_LoadConf(s32AoDevId, s32AoChnId, spchConfFile, spchConfSection);
    if (ret) {
        return ERROR;
    }

    /* Step 4: 使能通道 */
    ret = AK_MPI_AO_EnableChn(s32AoDevId, s32AoChnId);
    if (ret) {
        return ERROR;
    }

    FRAME_S stFrame = {0};
    /* Step 5: 播放音频数据 */
    while(1) {
      // Do something*
      ret = AK_MPI_AO_SetGain(s32AoDevId,  s32AoChnId, s32Gain);
      if (ret) {
         return ERROR;
      }
      ret = AK_MPI_AO_GetGain(s32AoDevId,  s32AoChnId, ps32Gain);
      if (ret) {
         return ERROR;
      }

      ret = AK_MPI_AO_SetMute(s32AoDevId, s32AoChnId, s32Enable, NULL);
      if (ret) {
         return ERROR;
      }
      ret = AK_MPI_AO_GetMute(s32AoDevId, s32AoChnId, ps32Enable, NULL);
      if (ret) {
         return ERROR;
      }
      ret = AK_MPI_AO_SendFrame(s32AoDevId, s32AoChnId, pu8SendPcmData,s32SendPcmLen, 	               ps32PlayPcmLen, s32TimeOut);
      if (ret) {
         return ERROR;
      }

    }
    /* Step 6: 关闭通道 */
    ret = AK_MPI_AO_DisableChn(s32AoDevId, s32AoChnId);
    if (ret) {
        return ERROR;
    }
    /* Step 7: 关闭设备 */
    ret = AK_MPI_AO_Disable(s32AoDevId);
    if (ret) {
        return ERROR;
    }
```

&emsp;&emsp;【接口重入性】

&emsp;&emsp;函数可重入。

> **注意：** 函数可重入，依赖AK_MPI_AO_Enable，支持在运行过程中调整输出音量，此接口调整的是模拟音量，模拟音量由驱动设置。

## AO模块配置文件参数说明

AI模块的配置文件为/etc/config/audio_config.ini，此文件中有多个section配置，def_far通过AK_MPI_AO_LoadConf接口配置参数。

def_far中的配置参数，配置参数含义如下：

| 配置参数        | 描述                                           | 取值范围                                                     |
| --------------- | ---------------------------------------------- | ------------------------------------------------------------ |
| EQ              |                                                |                                                              |
| eqLoad          | 是否装载EQ模块                                 | 0：不装载EQ模块，1：装载EQ模块。                             |
| eqmode          | EQ的模式                                       | 目前只能配置为user。                                         |
| preGain         | EQ总增益值                                     | [-12,12]，单位dB，允许配置两位小数。                         |
| bands           | 均衡器个数，共可设置10个均衡器。               | [0,10]，当均衡器格式大于0时，bands的值为一串字符串，格式为：bands="<#band>, <band0_param>, <band1_param>, ..." bandx_param的格式为： <type> <freq_Hz> <gain_dB> <Q> <bypass> type 取值 ： hpf, HPF, lpf, LPF, hsf, HSF, lsf, LSF, pf1, PF1 ； freq_Hz为进行滤波的频段，取值范围：20 <= freq <= 采样率/2/1.2，单位Hz。 gain_dB为每个频带的增益值，范围：（-32,32），缺省值为0，当配置的Type为lsf或者hsf或者pf1时，Gain如果配置为0会认为是无效配置。 Q为频带的Q值，band Q的取值范围0<=x.xxx < 采样率/(2*freqs)，且x.xxx值必须小于64.000，缺省值为0。 bypass 为是否忽略本条设置，0：不忽略本条设置，1：忽略本条设置。 |
| NR              |                                                |                                                              |
| nrEna           | NR是否使能。                                   | 0：不使能，1：使能。                                         |
| noiseSuppressDb | 降噪强度，其值为负数，负值越大，降噪强度越高。 | 范围：[-60,0)，缺省值为-40。 **注意：降噪强度越大，音频失真度越大。** |
| VOLUME          |                                                |                                                              |
| volLoad         | 是否装载ASLC模块。                             | 0：不装载ASLC模块，1：装载ASLC模块。                         |
| limit           | 输入端的限幅。                                 | 范围：(0,1]，缺省值为1。                                     |
| vol_dB          | 数字增益音量。                                 | 范围：[-90, 20]，单位dB。                                    |
| gain            | AI模块驱动增益。                               | DAC gain范围：[-2]                                           |
| mute            | AI采集声音是否配置为静音。                     | 0：非静音，1：静音                                           |
| echoMode        | 音效处理库的模式。                             | normal：普通模式                                             |
| HS(暂不支持)    |                                                |                                                              |
| hsLoad          | 是否装载HS模块。                               | 0：不装载HS模块，1：装载HS模块                               |
| hsEna           | hs是否使能。                                   | 0：不使能，1：使能。                                         |
| hsAlgorithm     | 算法选择                                       | 1和2可供选择                                                 |
| hsDurationMs    | 周期时间                                       | 默认5000                                                     |
